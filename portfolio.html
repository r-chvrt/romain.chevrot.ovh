PoC API Gateway

PoC Apache APISIX

Évaluation d'APISIX comme API Gateway cloud-native.

Contexte

Trouver une gateway performante, pilotable en GitOps et native Kubernetes.

Réalisé

  • Déploiement sur Kubernetes (Helm, etcd) avec l'Ingress Controller
  • Routes déclarées en CRDs
  • Tests des plugins : auth (JWT, OIDC), rate limiting, observabilité
  • Benchmark et comparatif avec l'existant

Résultat

Grille de décision et environnement de démo reproductible.

  • APISIX
  • Kubernetes
  • Helm
  • etcd
  • OIDC
  • Prometheus
PoC API Gateway · Sécurité

PoC HashiCorp Vault × Kong

Centralisation des secrets de Kong dans HashiCorp Vault.

Contexte

Des secrets stockés en clair dans la configuration de la gateway.

Réalisé

  • Déploiement de Vault et des moteurs KV et PKI
  • Références {vault://…} dans la configuration Kong
  • Rotation des credentials et des certificats TLS
  • Policies au moindre privilège et audit des accès

Résultat

Plus aucun secret en clair, accès tracés.

  • Kong
  • HashiCorp Vault
  • PKI / TLS
  • Kubernetes
Outil API Gateway · CI/CD

Kong Portal

Un résumé lisible de la configuration Kong, publié sur GitLab Pages.

Contexte

Rendre la configuration de la gateway consultable sans accès à Kong.

Réalisé

  • Extraction de la configuration Kong avec jq / yq
  • Rendu en pages HTML par un script Python
  • Génération et publication automatiques via GitLab CI

Résultat

Une documentation de la gateway à jour, sans effort manuel.

  • Kong
  • jq
  • yq
  • Python
  • GitLab CI
  • GitLab Pages
Migration OpenShift

Migration OpenShift 3 → 4

Migration d'une plateforme de production OpenShift 3.11 vers OpenShift 4.

Contexte

Fin de support de la v3, aucune mise à jour « in place » possible.

Réalisé

  • Inventaire des applications et des objets non portables
  • Installation des clusters OpenShift 4
  • Migration des workloads par vagues (MTC)
  • Adaptation CI/CD, routes et supervision

Résultat

Workloads migrés, clusters v3 décommissionnés.

  • OpenShift 4
  • OpenShift 3.11
  • MTC
  • Operators
  • CI/CD
